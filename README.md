# ファンタジーRPG 迷宮探索シミュレーター

## プロジェクト概要

このプロジェクトは、ダイクストラ法を含む3つのグラフ探索アルゴリズム（BFS、DFS、Dijkstra）を視覚的に比較するための教育用プログラムです。

### 問題設定

冒険者が古代遺跡の迷宮を探索するというファンタジーRPGの設定で、迷宮内の様々な地形による体力消費を考慮しながら、最適な経路を見つけます。

**地形タイプと体力消費量:**
- 石の通路: 1
- 草むらエリア: 3
- 泥濘地帯: 5
- 浅瀬の水路: 8

**目標:** 入口（左上）から宝物庫（右下）まで、体力消費を最小限に抑えて移動する

## なぜダイクストラ法が最適か

この問題では各地形に異なるコスト（重み）があります:

- **BFS**: 最短ステップ数のみを考慮（コストは無視）
- **DFS**: 経路探索だが最短を保証しない
- **Dijkstra**: 各エッジの重みを考慮し、最小コスト経路を保証

体力消費という実際のコストを最小化する必要があるため、ダイクストラ法が最適です。

## アルゴリズムの特徴

### BFS（幅優先探索）
- キューを使用
- 最短ステップ数を保証
- コストは考慮しない

### DFS（深さ優先探索）
- スタックを使用
- 深い経路を優先
- 最短経路を保証しない

### Dijkstra（ダイクストラ法）
- 優先度付きキューを使用
- 最小コスト経路を保証
- 地形コストを考慮（★この問題に最適）
